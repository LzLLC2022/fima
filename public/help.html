앱 접속 시 가장 먼저 표시되는 화면입니다. Account Owner(이름)와 PIN을 입력하여 입장합니다.

✏️ 입력 항목
항목설명
Account Owner등록된 이름을 입력합니다 (예: Lz, Eric). 대소문자 구분.
PIN설정한 PIN 번호. PIN 없이 등록된 경우 빈칸으로 입력.
💡 샘플 보기 버튼을 누르면 PIN 없이 샘플 데이터로 앱을 둘러볼 수 있습니다.

조회 > 현황 조회 탭

보유 자산의 현재 상태를 한눈에 확인하는 메인 화면입니다. 상단 새로고침 버튼을 누르면 최신 시세를 반영한 평가액을 조회합니다.

🔎 조회 조건
  • Account Owner — 복수의 계좌 소유자가 있을 때 특정 소유자만 필터링합니다.
  • Account — 일반, 연금, IRP 등 계좌 유형별로 필터링합니다.
💰 현금 / 입출금 현황

계좌별 순투자액(입금 − 출금)과 현금 잔액을 표시합니다.

📋 Stock(ETF) 현황 테이블
컬럼설명
종목명 / 티커클릭하면 종목 정보 팝업이 열립니다.

🏦 Bond(채권) 현황 테이블

조회 > 거래 조회 조회 탭

Google Sheets Ledger에 기록된 거래 내역을 조회·수정·삭제하는 화면입니다.

🔎 조회 조건
  • 기간 — 시작일 / 종료일로 범위 지정.
  • Account — 계좌 유형 필터.
  • Ticker — 특정 종목코드로 검색.
  • Trade — Buy / Sell / Dividend 등 거래 유형 필터.
✏️ 수정 / 🗑 삭제

조회 결과 각 행의 수정 버튼을 누르면 수정 모달이 열립니다. 모든 필드를 직접 편집할 수 있으며, 해외 거래의 경우 Tax 필드 아래에 💱 세금 KRW로 입력 버튼이 표시되어 KRW로 출금된 세금을 직접 입력할 수 있습니다.

조회 > 리포트 조회 탭

포트폴리오 성과를 다양한 차트와 테이블로 분석하는 화면입니다. Account Owner별로 확인할 수 있습니다.

🗂 포트폴리오 요약 카드
  • 순 투자액 — 입금액 − 출금액 합계.
  • 평가액 — 현재 보유 자산 시장가치 합계 (KRW).
  • 평가 손익 / 수익률 — 평가액 − 순투자액.
📅 기간별 손익 (YTD / MTD / Daily)
  • YTD — 연초(1월 1일) 이후 손익.
  • MTD — 월초(1일) 이후 손익.
  • Daily — 전일 종가 대비 손익.
📉 월별 누적 수익률 비교 차트

포트폴리오와 KOSPI·S&P500·NASDAQ을 분석 시작 첫 월 기준 누적 등락률로 비교합니다. 우상단 버튼으로 각 라인을 표시/숨김 토글할 수 있습니다.

💰 월별 수익금액 차트

매월 손익 변동금액(만원 단위)을 바 차트로 표시합니다. 파란색: 수익, 빨간색: 손실.

🎁 월별 배당금 현황

연도별·월별 수령 배당금을 표시합니다. 올해 미수령 달은 예상 배당 행에 Yahoo Finance 주당월배당 × 현재수량으로 예측값(보라색 이탤릭)을 표시합니다.

ℹ️ 한국 ETF의 경우 Yahoo Finance에 기준일(record date) 기준으로 배당 데이터가 저장되어 있어, 실제 지급월(기준일 +2개월)로 자동 보정됩니다.

조회 > 리밸런싱 조회 탭

현재 포트폴리오와 목표 비중을 비교하여 매수/매도가 필요한 금액을 계산해주는 화면입니다.

  • 각 종목의 목표 비중(%)을 직접 입력하면 현재 평가금액 기준으로 필요한 조정금액을 계산합니다.
  • 추가투자 금액을 입력하면 추가 자금 투입 시 필요한 매수금액까지 함께 계산합니다.
  • 결과는 양수(매수 필요) / 음수(매도 필요)로 색상 구분하여 표시합니다.
👀

조회 > 관심종목 조회 탭

보유 여부와 관계없이 관심 있는 종목의 시세를 실시간으로 모니터링하는 화면입니다.

  • Google Sheets WatchList 시트에 티커를 등록하면 자동으로 불러옵니다.
  • 현재가, 등락률, 52주 고가/저가, 배당률(TTM) 등을 표시합니다.
  • 종목명 클릭 시 종목 정보 팝업이 열립니다.
✏️

입력관리 > 거래 입력 입력관리 탭

새로운 거래를 Google Sheets Ledger에 기록하는 화면입니다. 입력 후 미리보기에서 내용을 확인하고 확인 저장을 눌러야 실제로 저장됩니다.

Buy — 매수 Sell — 매도 Dividend — 배당금 수령 Dividend-Stock — 배당 주식 재취득 Deposit — 입금 Withdraw — 출금 Split — 액면분할 Merge / Reverse-Split — 액면병합

Date *거래 일자전체
Trade *거래 유형전체

Region *국가/통화 (예: USA (USD), Korea)전체
Asset Type *Stock / ETF / Bond / Cash 등전체
Ticker *종목코드 (자동완성 지원)전체
Price체결가격 (거래 통화 기준)Buy / Sell
Currency (환율)1 외화 = ? KRW (해외 거래 전용)해외 거래
Quantity체결 수량Buy / Sell
Dividend주당 배당금 (거래 통화 기준)Dividend

Charge수수료전체
Comment 선택메모전체
💱 세금 KRW 직접 입력 (해외 배당)

해외 배당 수령 시 배당금은 외화(USD 등)로 입금되지만, 세금(원천징수)은 KRW로 출금되는 경우가 있습니다.

이런 경우 Tax 필드 아래 💱 세금 KRW로 입력 버튼을 클릭하면:

  • Tax 필드가 KRW 직접 입력 모드로 전환됩니다.
  • 입력 중 "≈ X.XXXX USD (저장값)"으로 환율 역산값을 실시간 표시합니다.
  • 저장 시 자동으로 Currency(환율)로 나누어 USD 기준값으로 변환 저장됩니다.
💡 예시 — TLT 배당: Dividend 31.53 USD, Tax 7,070 KRW, 환율 1,456.8 입력 시 Tax는 7,070 ÷ 1,456.8 ≈ 4.8531 USD로 자동 변환됩니다.
💱 해외 Buy 환전 방법

해외 주식 매수(Buy) 시 환전 방법을 선택할 수 있습니다:

  • 전체 자동환전 — 매입 대금 전액을 원화에서 환전하여 매수. Buy 1건 + Withdraw(원화) 1건 자동 생성.
  • 일부 자동환전 — 보유 외화 일부 사용, 나머지만 환전. 보유 외화 사용금액 직접 입력.
  • 환전 없음 — 기보유 외화로 전액 매입. Buy 1건만 기록.

정보변경

우상단 ⚙️ 정보변경 버튼을 누르면 열리는 설정 화면입니다.

  • PIN 변경 — 현재 PIN 확인 후 새 PIN으로 변경.
  • 이메일 변경 — 일일 포트폴리오 리포트 수신 이메일 주소 변경.
💡 매일 오전 자동으로 포트폴리오 리포트 이메일이 발송됩니다. 이메일 수신을 원하지 않는 경우 Google Sheets Master 시트의 EmailRecv 컬럼을 N으로 설정하세요.
