로그인 화면

앱 접속 시 가장 먼저 표시되는 화면입니다. Account Owner(이름)와 PIN을 입력하여 입장합니다.

✏️ 입력 항목
항목설명
Account Owner등록된 이름을 입력합니다 (예: Lz, Forest). 대소문자 구분. Vercel 환경변수의 Google Spreadsheet와 연결되는 로그인 키입니다.
PIN설정한 PIN 번호. PIN 없이 등록된 경우 빈칸으로 입력.
💡 샘플 보기 버튼을 누르면 PIN 없이 샘플 데이터로 앱을 둘러볼 수 있습니다.
👤

AccountOwner 전환 (우측 상단 드롭다운)

로그인 후 화면 우측 상단의 드롭다운에서 투자 AccountOwner를 선택하면, 해당 계좌의 거래 데이터만 필터링하여 조회합니다.

🔑 로그인ID vs 투자 AccountOwner
구분역할예시
로그인IDVercel 환경변수를 통해 Google Spreadsheet를 찾는 키. 로그인 후 변경되지 않습니다.Lz, Forest
투자 AccountOwnerLedger 시트 내 Account Owner 컬럼 값. 드롭다운으로 전환하며 데이터를 필터링합니다.Forest, TEST
🔄 전환 동작
  • 드롭다운에서 다른 AccountOwner를 선택하면 현황·거래 조회·리포트·리밸런싱 탭의 이전 결과가 즉시 초기화됩니다.
  • 이후 각 탭에서 조회 버튼을 누르면 선택한 AccountOwner의 데이터만 표시됩니다.
  • 거래 입력 시에도 드롭다운에서 선택된 AccountOwner가 Ledger에 자동으로 기록됩니다.
ℹ️ 드롭다운 목록은 로그인한 사용자의 Google Spreadsheet Ledger 시트의 Account Owner 컬럼 고유값에서 자동으로 읽어옵니다.

조회 > 현황 조회 탭

보유 자산의 현재 상태를 한눈에 확인하는 메인 화면입니다. 상단 새로고침 버튼을 누르면 최신 시세를 반영한 평가액을 조회합니다.

🔎 조회 조건
  • Account Owner — 복수의 계좌 소유자가 있을 때 특정 소유자만 필터링합니다.
  • Account — 일반, 연금, IRP 등 계좌 유형별로 필터링합니다.
💰 현금 / 입출금 현황

계좌별 순투자액(입금 − 출금)과 현금 잔액을 표시합니다.

🌏 Region 그룹핑

Stock(ETF) 현황 테이블의 종목은 Region별로 묶어서 표시됩니다. Region 헤더 행을 클릭하면 해당 그룹의 종목 목록을 접거나 펼칠 수 있습니다. (▼ 펼침 / ▶ 접힘)

조회 > 거래 조회 조회 탭

Google Sheets Ledger에 기록된 거래 내역을 조회·수정·삭제하는 화면입니다.

🔎 조회 조건
  • 기간 — 시작일 / 종료일로 범위 지정.
  • Account — 계좌 유형 필터.
  • Ticker — 특정 종목코드로 검색.
  • Trade — Buy / Sell / Dividend 등 거래 유형 필터.
🔎 행 클릭 → 거래 상세조회 모달

표에서 좁은 컬럼 때문에 잘려 보이는 값(긴 Comment, Account Owner 등)이나 외화 거래의 KRW 환산값을 한번에 확인할 수 있도록, 결과 행을 클릭하면 상세 모달이 열립니다.

  • 전체 필드 표시 — 헤더 기반으로 시트의 모든 컬럼(표에 안 보이는 것 포함)을 거래 기본정보 · 종목정보 · 거래금액 · 매입정보 · 메모 섹션으로 그룹핑하여 표시.
  • 외화 거래 KRW 환산 — Region이 KRW가 아닌 거래는 Price · 합계(Price × Qty) · Dividend · Tax · Charge에 현지통화 값과 함께 ≈ X KRW 환산값을 병기.
  • 수정/삭제 버튼 분리 — 행 끝의 ✏️ 수정 / 🗑 삭제 버튼 클릭은 상세 모달로 이어지지 않고 기존대로 동작합니다.
  • 상세 → 수정 바로가기 — 상세 모달 푸터의 ✏️ 수정 버튼으로 같은 행을 바로 수정 모달로 이어서 열 수 있습니다.
➕ 거래입력 팝업 (조회 결과에서 바로 입력)

조회를 한 번이라도 실행하면 조회 조건 우측에 ➕ 거래입력 버튼이 노출됩니다. 이 버튼은 입력관리 > 거래 입력 화면을 그대로 팝업으로 띄워, 탭 이동 없이 신규 거래를 기록할 수 있게 합니다.

  • 동일한 입력 UX — 콤마 자동 포맷 · KRW 환산 뱃지 · 환전 옵션 · 미리보기 모달 등 거래 입력 탭의 모든 기능을 그대로 사용합니다.
  • 저장 후 자동 새로고침 — 팝업에서 저장이 완료되면 팝업이 닫히고 거래조회 목록이 즉시 재조회되어, 방금 저장한 거래가 결과에 반영됩니다.
  • Account Owner 자동 적용 — 현재 상단 드롭다운에서 선택된 AccountOwner가 그대로 저장됩니다.
✏️ 수정 / 🗑 삭제

조회 결과 각 행의 수정 버튼을 누르면 수정 모달이 열립니다. 거래 입력 화면과 동일한 UX로 통일되어 있습니다:

  • 세자리 콤마 자동 포맷 — 모든 숫자 입력(Price/Currency/Quantity/Dividend/Tax/Charge/Purchase 등)에 입력 즉시 천단위 콤마가 들어갑니다.
  • 외화 거래 KRW 환산 뱃지 — 환율(Currency)이 입력되어 있고 Region이 KRW가 아니면 Price·Dividend·Tax·Charge 옆에 ≈ XXX KRW 뱃지가 표시됩니다.
  • 💱 세금 KRW로 입력 토글 — 해외 거래는 Tax 필드 아래에 토글이 표시되어, KRW로 출금된 세금을 직접 입력하면 저장 시 외화로 자동 역산됩니다.
  • 저장 전 확인 미리보기 — 저장 클릭 시 즉시 저장되지 않고 입력 화면과 동일한 미리보기 모달이 떠서 거래 기본정보/종목정보/거래내용을 확인할 수 있고, 확인 저장을 한 번 더 눌러야 실제 시트에 반영됩니다.
  • Account Owner 필수 — 저장·수정 모두 Account Owner가 비어 있으면 차단됩니다. 빈 값으로 입력된 과거 행을 수정할 때는 원본 값이 자동으로 유지됩니다.

조회 > 리포트 조회 탭

포트폴리오 성과를 다양한 차트와 테이블로 분석하는 화면입니다. Account Owner별로 확인할 수 있습니다.

🗂 포트폴리오 요약 카드
  • 순 투자액 — 입금액 − 출금액 합계.
  • 평가액 — 현재 보유 자산 시장가치 합계 (KRW).
  • 평가 손익 / 수익률 — 평가액 − 순투자액.
📅 기간별 손익 (YTD / MTD / Daily)
  • YTD — 연초(1월 1일) 이후 손익.
  • MTD — 월초(1일) 이후 손익.
  • Daily — 전일 종가 대비 손익.
📉 월별 누적 수익률 비교 차트

포트폴리오와 KOSPI·S&P500·NASDAQ을 분석 시작 첫 월 기준 누적 등락률로 비교합니다. 우상단 버튼으로 각 라인을 표시/숨김 토글할 수 있습니다.

💰 월별 수익금액 차트

매월 손익 변동금액(만원 단위)을 바 차트로 표시합니다. 파란색: 수익, 빨간색: 손실.

🎁 월별 배당금 현황

연도별·월별 수령 배당금을 표시합니다. 올해 미수령 달은 예상 배당 행에 Yahoo Finance 주당월배당 × 현재수량으로 예측값(보라색 이탤릭)을 표시합니다.

ℹ️ 한국 ETF의 경우 Yahoo Finance에 기준일(record date) 기준으로 배당 데이터가 저장되어 있어, 실제 지급월(기준일 +2개월)로 자동 보정됩니다.
🌏 Region 그룹핑

보유 종목별 수익률 테이블도 Region별로 묶어서 표시됩니다. Region 헤더 행을 클릭하면 접기/펼치기가 가능합니다.

📋 보유 종목별 수익률 테이블

해외주식(USD 등)은 각 셀에 현지통화 값 / KRW 환산값 / 단가·수량을 함께 표시합니다. 한국 종목은 KRW 환산 라인이 생략됩니다.

조회 > 관심종목 조회 탭

보유 여부와 관계없이 관심 있는 종목의 시세를 실시간으로 모니터링하는 화면입니다.

  • Google Sheets WatchList 시트에 티커를 등록하면 자동으로 불러옵니다.
  • 현재가, 등락률, 52주 고가/저가, 배당률(TTM) 등을 표시합니다.
  • 종목명 클릭 시 종목 정보 팝업이 열립니다.
📨 변동 알림 (텔레그램, 매시간)

관심종목과 보유종목의 현재가가 전일 종가 대비 본인이 설정한 상승/하락 임계값 이상 변동되면 1시간마다 텔레그램으로 알림이 전송됩니다. 임계값은 우측 상단 ⚙️ 정보 변경에서 사용자별로 설정합니다.

  • 모니터링 대상 — (1) 보유종목: Ledger 시트에서 현재 보유 중인 종목 (Buy − Sell + Split 누적). (2) 관심종목: Favorate 시트에 등록된 종목 중 보유하지 않은 것.
  • 기준가 — 직전 영업일 종가 (Yahoo Finance / NAVER 금융의 changepct 사용).
  • 주기 — GitHub Actions cron(매시 정각, UTC) → /api/watchlist/alert 호출.
  • 판정 기준 — 상승 종목은 본인이 설정한 상승 % 이상, 하락 종목은 하락 % 이상일 때 알림. 두 값을 각각 다르게 설정 가능 (예: 상승 3% / 하락 7%).
  • 발송 단위 — 보유종목과 관심종목을 각각 독립된 텔레그램 메시지로 발송. 변동된 종목이 있는 그룹만 발송 (둘 다면 메시지 2건). 각 그룹 내에서는 변동률 큰 순으로 정렬. 메시지 제목에는 임계값을 +X% 이상, -Y% 이하 형태로 표기.
  • 중복 제거 — 보유종목과 관심종목에 같은 ticker가 있으면 보유종목 섹션에만 표시.
  • 박스 표시 — 텔레그램 인용 박스(<blockquote>)로 종목별 정보를 묶음. 박스 색은 본인 텔레그램의 테마 액센트 컬러(Settings → Appearance → Color)에 따라 표시되며, 상승/하락에 따른 박스 색 분리는 텔레그램 API 제약상 불가능합니다. 종목 앞 🔴(상승) / 🔵(하락)으로 시각 구분.
  • 수신 토글 — 정보 변경 화면의 알림 수신 체크박스를 해제하면 알림 일시 중지. 다시 켜기 전까지 발송 안 됨.
  • 중복 정책 — 변동률이 임계값 이상 유지되는 동안 매시간 반복 발송. 별도의 dedup 처리 없음.

정보 변경 (PIN · E-Mail · 텔레그램 알람) 우측 상단 버튼

로그인 후 우측 상단의 ⚙️ 정보 변경 버튼을 클릭하면 모달이 열리며, 세 가지 사용자 설정을 한 곳에서 관리할 수 있습니다.

🔐 PIN 변경

현재 PIN을 확인한 뒤 새 PIN(4자리 이상)으로 변경. Master 시트의 Pin 컬럼에 저장됨.

✉️ E-Mail 변경

일일 리포트를 받을 이메일 주소와 수신 여부를 설정. Master 시트의 Email / EmailRecv 컬럼에 저장됨.

📨 관심종목 알람(텔레그램)

관심종목 변동 알림을 텔레그램으로 받기 위한 설정. 입력값은 자동으로 Master 시트의 Telegram / TelegramRecv / TelegramUpPct / TelegramDownPct 컬럼에 저장됨 (헤더가 없으면 자동 생성).

항목설명
텔레그램 ID본인의 chat_id (숫자, 9~10자리). 채널은 -100... 형식 음수도 허용. 확인 방법은 아래 참조.
알림 수신체크: 알림 발송 / 해제: 일시 중지. 일시적으로 끄고 싶을 때 사용.
상승 %상승 알림 임계값. 예: 5를 입력하면 +5% 이상 종목만 알림. 범위 0~100, 소수점 입력 가능 (예: 2.5).
하락 %하락 알림 임계값. 입력은 양수(예: 5), 실제 판정은 -5% 이하.
🆔 텔레그램 ID 확인 방법
  1. 봇 찾기 — 텔레그램에서 관리자가 알려준 봇 username(FiMa 알림) 검색 → 1:1 대화창 진입 → 하단 Start 버튼 클릭 (또는 /start 입력).
  2. 봇의 응답에서 ID 확인 — 봇이 자동으로 "당신의 텔레그램 ID 입니다: 123456789" 메시지를 보내줍니다. 그 숫자를 길게 눌러 복사.
  3. fima 정보 변경에 입력 — 위 chat_id를 텔레그램 ID 칸에 붙여넣기 → 알림 수신 체크 → 상승 % / 하락 % 설정 → 텔레그램 설정 저장.
ℹ️ 봇이 응답하지 않거나 ID를 다시 보고 싶을 때는 봇 대화창에서 /start 또는 /myid 를 다시 입력하세요. 봇 username을 모르면 관리자에게 문의.

💱 세금 KRW 직접 입력 (해외 배당)

해외 배당 수령 시 배당금은 외화(USD 등)로 입금되지만, 세금(원천징수)은 KRW로 출금되는 경우가 있습니다.

이런 경우 Tax 필드 아래 💱 세금 KRW로 입력 버튼을 클릭하면:

  • Tax 필드가 KRW 직접 입력 모드로 전환됩니다.
  • 입력 중 "≈ X.XXXX USD (저장값)"으로 환율 역산값을 실시간 표시합니다.
  • 저장 시 자동으로 Currency(환율)로 나누어 USD 기준값으로 변환 저장됩니다.
💡 예시 — TLT 배당: Dividend 31.53 USD, Tax 7,070 KRW, 환율 1,456.8 입력 시 Tax는 7,070 ÷ 1,456.8 ≈ 4.8531 USD로 자동 변환됩니다.
💱 해외 Buy 환전 방법

해외 주식 매수(Buy) 시 환전 방법을 선택할 수 있습니다:

  • 전체 자동환전 — 매입 대금 전액을 원화에서 환전하여 매수. Buy 1건 + Withdraw(원화) 1건 자동 생성.
  • 일부 자동환전 — 보유 외화 일부 사용, 나머지만 환전. 보유 외화 사용금액 직접 입력.
  • 환전 없음 — 기보유 외화로 전액 매입. Buy 1건만 기록.
